# Day 01 — Modern JavaScript Basics

Welcome to **Day 01** of my **30-Day React Developer Bootcamp**. This day focuses on building a strong foundation in **Modern JavaScript**, which is essential before learning React.

---

## Objective

Learn the core JavaScript concepts required for React development:

* `let`, `const`, `var`
* Variables and data types
* Operators
* Conditional statements
* Loops
* Functions
* Basic problem-solving using JavaScript

## Programs Included

### 1. `basic.js`

Demonstrates variable declarations using `let`, `const`, and `var`.

#### Output

```text
Vamsi Krishna 22 Bangalore
```

---

### 2. `evenOdd.js`

Checks whether a number is **Even** or **Odd**.

#### Example

```text
7 is Odd
10 is Even
```

---

### 3. `largestOfThree.js`

Finds the **largest number among three numbers**.

#### Example

```text
Largest: 45
```

---

### 4. `reverseString.js`

Reverses a given string using JavaScript string methods.

#### Example

```text
react → tcaer
```

---

### 5. `factorial.js`

Calculates the **factorial of a number** using a `for` loop.

#### Example

```text
Factorial of 5: 120
```

---

### 6. `palindrome.js`

Checks whether a string is a **palindrome**.

#### Example

```text
madam: true
hello: false
```
